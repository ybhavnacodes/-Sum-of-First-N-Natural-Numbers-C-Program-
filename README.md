# Sum of First N Natural Numbers (C Program)

This simple C program calculates the **sum of the first N natural numbers** using the mathematical formula:

\[
\text{Sum} = \frac{n(n+1)}{2}
\]

---

## 🧩 How It Works
1. The program takes an integer input `n` from the user.
2. It applies the formula `(n * (n + 1)) / 2`.
3. It prints the result.
